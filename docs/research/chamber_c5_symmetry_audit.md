# C5 symmetry in the oriented-chamber arena

## Headline

The proposed symmetry no-go is false.  There are exact oriented-chamber
partition algebras which simultaneously satisfy first order, orientability,
integral Poincare duality, and retain a nontrivial `C5` subgroup of the
rotational `A5` action.

This is an existence result in a declared subfamily.  It is not a global
minimum theorem and it does not derive a physical matter algebra.

## Arbitrary-partition SAT screen

An SMT query ranges over every set partition of the 120 oriented chambers.
The equivalence relation, rather than the arbitrary integer names of its
blocks, is required to be invariant under a representative rotation.

- order two: `UNSAT` for first order plus orientability;
- order three: `SAT`, with a 19-block witness whose intersection form has
  rank 18;
- either order-five conjugacy class: `SAT`, with 26-block witnesses whose
  intersection forms have rank 12.

Thus the broad statement that no first-order orientable partition retains a
nontrivial `A5` stabilizer is **REFUTED**.  The first SAT witnesses do not
satisfy Poincare duality, so they alone do not give viable finite triples.

## Exact C5 and Poincare-dual witness

The 90 chamber-edge pairs define a binary contraction family.  Requiring the
binary contraction vector itself to be invariant under a fixed `C5` leaves
18 affine orbit bits, hence exactly `2^18 = 262144` assignments.  Exhaustion
produces a concrete witness for which the verifier checks over the integers:

- first order;
- metric-dimension-zero orientability;
- invariance of the resulting partition under `C5`;
- determinant of the intersection matrix equal to `1` and Pfaffian equal to
  `+1` or `-1`;
- the complete stabilizer inside the 60 rotations.

The bit string and all 120 block labels are printed by the verifier, so this
existence certificate can be checked without trusting the search.

**DERIVED:** a `C5`-symmetric, orientable, first-order, integrally
Poincare-dual partition exists in the invariant-vector contraction
subfamily.

The exact witness has 30 blocks, determinant 1, Pfaffian `+1`,
stabilizer order 5 and
`dim_C Omega_D^1=110`.  It therefore **REFUTES** 126 as the proposed global
minimum of the chamber one-form dimension.  The earlier 126 result survives
only as a local minimum in its explicitly exhausted radius-two neighborhood.
The true global minimum is still **OPEN**, with certified upper bound 110.

## The exact scope gap

The map from contraction vectors to partitions takes transitive closure and
is not injective.  Consequently, a non-invariant set of contracted edges may
generate an invariant partition.  Therefore

`partitions generated by C5-invariant contraction vectors`

is only a subset of

`C5-invariant partitions generated by arbitrary contraction vectors`.

The exhaustion proves a statement about the first set only.  It does not
exhaust the second set, and it does not exhaust all arbitrary invariant
partitions.  Any use of the word "global" beyond the first set would be
incorrect.
