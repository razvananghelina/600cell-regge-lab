# Protocol: global shape matching of equal-scale prism shifts

Date: 2026-08-19

Prior-art gate commit: `4a9ea11`.

This protocol is frozen before constructing the matching matrix and before
reading any carrier nullity or symmetry-orbit count.

## 1. Frozen hypotheses

Use the closed regular 600-cell boundary

```text
f=(120,720,1200,600)
```

and, as a subdivision consequence rather than a second large rank problem,
the certified projected rank-edgewise carrier

```text
f=(19680,134880,230400,115200).
```

On every spatial tetrahedron use the equal-scale Lorentzian cell
`Delta_3 x I` with:

1. identical bottom and top tetrahedral metrics;
2. one common vertical squared length `-rho`, `rho>0`;
3. the local three-parameter tangential translation family established by
   the prism-rigidity verifier;
4. complete labelled metric matching of each shared lateral triangular
   prism;
5. no staircase diagonal, order, action coefficient, normal or cross-edge
   length supplied as input.

Only kinematic shape matching is tested.  No Regge equation, continuum
target, spectrum or desired physical multiplicity may enter the verifier.

## 2. Direct local-variable matching matrix

For every oriented tetrahedron

```text
sigma=(v0,v1,v2,v3)
```

represent its constant shift covector by the three values

```text
a_sigma,i = alpha_sigma(vi-v0),  i=1,2,3.
```

For every shared triangular face, choose its two lexicographically first
independent oriented edges.  Add two equations requiring the evaluations of
the incident tetrahedral covectors on those edges to agree.  This produces a
literal integer face-matching matrix

```text
C : R^(3*T) -> R^(2*F).
```

The primary verifier must compute its rank modulo a disclosed prime.  A
modular rank is a rigorous lower bound on rational rank.  The separately
constructed vertex-potential map

```text
B : R^V -> R^(3*T),
(B phi)_(sigma,i)=phi(vi)-phi(v0)
```

must satisfy `C B=0` exactly.  Since the vertex graph is connected,
`rank(B)=V-1`; this gives the rational upper bound

```text
rank(C) <= 3*T-(V-1).
```

If the modular lower bound reaches this upper bound, then over the rationals

```text
ker(C)=im(B),  dim ker(C)=V-1=119.
```

No singular-value threshold may decide this equality.

## 3. Independent cochain checksum inside the primary run

Construct the oriented simplicial coboundaries

```text
d0 : C^0 -> C^1,
d1 : C^1 -> C^2.
```

Verify `d1*d0=0` exactly.  The modular rank of `d1`, together with the exact
rank of `d0`, must return `b1=0` and the same closed-one-form dimension
`V-1`.  This checksum uses different unknowns from `C`; it is not accepted as
the later adversarial replication by itself.

## 4. Controls

### Positive local control

One isolated tetrahedron has no inter-cell face equations and must retain
exactly three local shift variables.

### Topological negative control

Use the periodic `3 x 3` triangulation of the two-torus with 9 vertices, 27
edges and 18 triangles.  Its exact cochain ranks must give

```text
b0=1, b1=2, b2=1,
dim ker(d1)=V-1+b1=10,
```

so the false universal formula `V-1` fails by exactly two.

## 5. Finite integration check

Choose `rho=1` and compare the zero potential with the nonconstant potential
that is one at the lexicographically first 600-cell vertex and zero at every
other vertex.

For each tetrahedron, let `G_sigma` be the positive spatial Gram matrix of
its three edge vectors from `v0`, and let `a_sigma` contain the three
potential differences.  Define the local Lorentzian prism Gram matrix

```text
H_sigma = [ G_sigma   a_sigma ],
          [ a_sigma^T   -rho  ].
```

The verifier must check:

- every Schur complement is strictly negative;
- bottom and top spatial edges are unchanged;
- every vertical squared length is `-rho`;
- the induced Gram matrices on every shared lateral triangular prism agree;
- at least one cell has a different absolute four-volume from the zero
  potential, using

```text
|det(H_sigma)| = det(G_sigma)
                 * (rho+a_sigma^T G_sigma^-1 a_sigma).
```

This is a finite family of shape-matched Lorentzian cells with identical
declared natural lengths.  It is not a solution of the Regge equations.

## 6. Symmetry census

For the declared group generated by left and right binary-icosahedral
actions and quaternion conjugation:

1. compute the vertex orbits of the regular 600-cell;
2. compute the vertex orbits of the projected rank-edgewise carrier;
3. report, without a desired target, the invariant potential-gradient
   dimension

```text
number_of_vertex_orbits - 1.
```

The regular carrier is expected to have one orbit and therefore no nonzero
invariant shift.  No fine-carrier orbit number is frozen here.

## 7. Verdicts fixed before execution

Return

```text
GLOBAL_STATIC_LENGTH_DATA_UNDERDETERMINED
```

only if all of the following hold:

- the direct 600-cell matching kernel has dimension 119;
- it equals the vertex-potential image;
- the cochain checksum and both controls pass;
- the finite nonconstant potential shape-matches exactly at the
  combinatorial level and within the frozen `1e-9` geometric tolerance;
- at least one cell volume changes while every declared natural length stays
  fixed.

Return `MATCHING_THEOREM_REFUTED` if an exact rank or control disagrees.
Return `NUMERICALLY_OPEN` if only a floating geometric gate is unresolved.

## 8. Classification boundary

A passing result will be labelled **DERIVED KINEMATIC** and will refute a
canonical static length-only cellular Hessian.  It will not establish that
the 119 modes are gauge, physical shifts or constraints.  In fact, because
they form a scalar-gradient sector rather than three arbitrary functions per
vertex, calling them the full ADM shift would be false.

Only the registered mission verifier and static guards may be run.  The full
suite is explicitly excluded.
