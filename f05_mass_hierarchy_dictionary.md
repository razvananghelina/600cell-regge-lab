## Conditional statement: form of an imported multiplicative hierarchy map

Assume one wants a hierarchy map
\[
R:L\to \mathbb{R}_{>0}
\]
with the following three properties:

1. it depends only on the exact grading `w`;
2. it is multiplicative on the grading:
   \[
   R_{n+m}=R_n R_m;
   \]
3. its image lies in the intrinsic positive unit group generated by `\phi`.

Then necessarily
\[
R(a,b)=\phi^{k\,w(a,b)}
\qquad\text{for some } k\in \mathbb{Z}.
\]

If one further imposes primitive-step normalization, so that one unit of
grading corresponds to one primitive scale step, then
\[
k=\pm 1
\]
and therefore
\[
R(a,b)=\phi^{w(a,b)}
\qquad\text{or}\qquad
R(a,b)=\phi^{-w(a,b)}.
\]

## Why this is only conditional

Because `w:L\to Z` is surjective, any hierarchy map depending only on `w` is
equivalent to a map
\[
\widetilde R:\mathbb{Z}\to \mathbb{R}_{>0}.
\]
The multiplicativity condition makes `\widetilde R` a group homomorphism from
`(\mathbb{Z},+)` to `(\mathbb{R}_{>0},\times)`, so it has the form
\[
\widetilde R(n)=q^n
\]
for some `q>0`. If the image is required to lie in
\[
U_+(\mathbb{Z}[\phi])=\langle \phi\rangle,
\]
then `q=\phi^k` for some integer `k`, hence
\[
\widetilde R(n)=\phi^{kn}.
\]
Primitive-step normalization forces `|k|=1`.

This argument is mathematically correct, but it is **not** derived from the
discrete precursor alone. It depends on two imported assumptions:

1. multiplicativity of the hierarchy map;
2. restriction of the image to the positive unit group generated by `\phi`.

So the result is a consistency statement inside an FN-like flavor dictionary,
not an intrinsic theorem of the exact core.

## Consequence

This gives the strongest exact mass-language available at this stage:

- if one adopts an FN-like multiplicative hierarchy whose values lie in the
  positive unit group generated by `\phi`, then powers of `\phi` are forced;
- equivalently, one may write a suppression parameter
  \[
  \epsilon=\phi^{-1}
  \]
  and use
  \[
  R(a,b)=\epsilon^{\,w(a,b)}
  \]
  up to the sign convention for what counts as suppression vs enhancement.

So a Froggatt-Nielsen-like flavor dictionary is legitimate as a conditional
reading, but not as a derived mass mechanism.

## What this still does not fix

The exact data do **not** determine:

1. whether physical masses grow with `w` or shrink with `w`;
2. the anchor scale `m_*`;
3. species-dependent offsets;
4. the splitting of states that share the same exponent;
5. the full observed fermion spectrum.

Therefore the old strong formula
\[
m_f = m_e \phi^{n_f+\cdots}
\]
is not derived at this stage.

## Strongest honest statement

The strongest honest statement is:

- conditional flavor level:
  if one imports an FN-like multiplicative hierarchy with image in the
  positive unit group generated by `\phi`, then powers of `\phi` are forced;
- not yet:
  a derived fermion mass formula.

## Failure criterion check

`F05` would have failed if no monotone mass map could be justified without
forbidden input.

That failure **does** occur at the theorem level:

- no monotone physical mass map is derived from the exact data alone.

What survives is only the weaker conditional statement:

- once an FN-like multiplicative map is imported, the `\phi`-power form is
  rigid up to sign and normalization.

## Decision

`F05` is closed in split form:

- `Conditional flavor statement`:
  an imported FN-like multiplicative hierarchy with image in the positive unit
  group generated by `\phi` is forced to take the form `\phi^{\pm w}`;
- `No-go warning`:
  no physical mass hierarchy map is derived from the exact data alone.
