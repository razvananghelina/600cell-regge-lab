# Uniqueness Theorem v3: Simple Edge Wilson Lines

## Main idea

The strongest bounded-search uniqueness principle found so far is:

`C1 + S => unique physical assignment`

where:

- `C1` is node irreducibility in `Z[phi]`;
- `S` is a simple edge-Wilson-line condition on the McKay tree.

This is stronger than:

- the current paper version `C1 + C2`;
- the intermediate version `C1 + Q + C2`.


## Node Constraint

For each fermion node `f`, assign

`z_f = a_f + b_f phi in Z[phi]`

with fixed bare exponents

`n_f = 5 a_f + 6 b_f in {0,3,5,11,11,16,17,19,26}`.

Constraint `C1`:

`z_f` is zero, a unit, or an irreducible element of `Z[phi]`.

Equivalently:

`|N(z_f)| in {0,1} union {p prime : p mod 5 in {0,1,4}}`.


## Edge Constraint

For each McKay edge `(i,j)`, define

`dz_ij = z_j - z_i`.

Constraint `S`:

`dz_ij in {0} union {+/- phi^r : r in Z} union {+/- 2 phi^r : r in Z}`.

So every edge Wilson line is either:

- zero,
- a pure power of the fundamental unit,
- or twice a pure power of the fundamental unit.


## Computational Theorem

Within the bounded domain `|t_f| <= 15` for

`(a,b) = (-n - 6t, n + 5t)`,

the constraints `C1 + S` select a unique assignment:

`[(0,0), (3,-2), (1,0), (1,1), (1,1), (2,1), (1,2), (-1,4), (4,1)]`.

This is verified by:

`reproducible/verify_uniqueness_simple_edges.py`

with counts:

- `543,129,600` assignments satisfy `C1` in `|t|<=15`;
- `1` assignment satisfies `C1 + S`.


## Edge Data of the Unique Solution

For the selected assignment, the edge differences are exactly:

- `z_u - z_e = -phi^{-3}`
- `z_d - z_u = 2 phi^{-1}`
- `z_s - z_d = phi`
- `z_mu - z_s = 0`
- `z_c - z_mu = 1`
- `z_tau - z_c = phi^{-1}`
- `z_brA - z_tau = 2 phi^{-1}`
- `z_brB - z_c = 2`

Thus every edge is in the simple class with coefficient in `{0, +/-1, +/-2}`.


## Why This Is Better Than Q

The previous edge quantization condition `Q`

`dz / sigma(dz) = +/- phi^k`

is still true, but it is now secondary.  In fact:

if `dz = +/- m phi^r` with `m in {1,2}`, then

`sigma(dz) = +/- m (-1/phi)^r`

and therefore

`dz / sigma(dz) = +/- phi^{2r}`.

So `S` implies an edgewise Galois quantization automatically.

This is conceptually better because `S` is a direct statement about the
allowed edge Wilson lines themselves, not about a derived ratio.


## Suggested Theorem

> **Theorem (Simple-edge Wilson-line selection, bounded-search form).**
> Let `z_f = a_f + b_f phi in Z[phi]` be assigned to the nine McKay-tree nodes,
> with fixed bare exponents `n_f = 5 a_f + 6 b_f` equal to
> `{0,3,5,11,11,16,17,19,26}`.
> Assume:
> 1. each `z_f` is zero, a unit, or an irreducible element of `Z[phi]`;
> 2. for every McKay edge `(i,j)`, one has
>    `z_j - z_i in {0} union {+/-phi^r} union {+/-2phi^r}`.
>
> Then, within the domain `|t_f| <= 15`, there is a unique assignment,
> namely
> `[(0,0), (3,-2), (1,0), (1,1), (1,1), (2,1), (1,2), (-1,4), (4,1)]`.


## Immediate Corollaries

1. The edge Galois-ratio quantization `Q` follows automatically.
2. The flatness sum `C2` is no longer needed as an independent selector in the
   bounded search.
3. The physical assignment is characterized by an exceptionally simple edge
   transport pattern:
   `(-phi^-3, 2phi^-1, phi, 0, 1, phi^-1, 2phi^-1, 2)`.


## Open Problem

The remaining nontrivial step is to derive `S` from a first-principles
framework statement, rather than imposing it as a bounded-search axiom.

The natural candidate interpretation is:

- edge Wilson lines are generated by the fundamental unit `phi`;
- only the two smallest amplitudes `1` and `2` occur because each McKay edge
  carries at most a double occupancy / doublet multiplicity.

That interpretation is not yet a theorem.
