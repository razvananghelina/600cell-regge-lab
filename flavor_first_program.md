# Flavor-First Program

Scop: reconstruirea partii de fizica a particulelor pornind de la nucleul
discret exact, dar fara a mai presupune sau salva o derivare a sectorului
gauge.

Principiu central:

- tratam structura discreta drept un posibil precursor de flavor;
- nu tratam teoria drept derivare completa a Standard Model;
- nu folosim niciun claim care depinde de ruta gauge cazuta.

## Ce este permis ca input

Doar rezultate care raman valide dupa no-go-urile gauge:

- seed-ul Fibonacci si bootstrap-ul `a_1 = 5`;
- realizarea `H4 -> 600-cell`;
- spectrul exact al 600-cell-ului;
- umbra McKay `2I -> \widetilde{E}_8`;
- theorem-ul cu `three stable chiral unit sectors`;
- theorem-ul `(a,b)` doar in forma lui exacta/conditionala declarata;
- rezultatele discrete de scalar response si spectral action;
- orice alta structura care nu foloseste derivarea gauge.

## Ce este interzis ca input

- orice ruta de tip `fiber -> A_5 -> gauge`;
- theorem-ul Lie ca sursa activa de fizica;
- `alpha`, `alpha_s`, `sin^2 theta_W` ca gauge couplings derivate;
- sectorul electroweak ca input inchis;
- orice claim care presupune gauge group deja obtinut.

## Tinta realista

Nu:

- "derived Standard Model".

Da:

- "discrete flavor hierarchy candidate";
- "emergent suppression-charge model";
- "residual-symmetry / texture candidate" daca trece filtrele.

## Standard de lucru

Pentru fiecare pas nou cerem:

1. `Exact input`
2. `Flavor target`
3. `Allowed dictionary`
4. `Failure criterion`
5. `Decision`

## Prima intrebare a programului

Care este setul maxim de date flavor-relevante care supravietuiesc exact dupa
caderea rutei gauge?
